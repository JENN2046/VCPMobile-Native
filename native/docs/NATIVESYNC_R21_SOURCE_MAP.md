## New Rust compatibility component

`core/src/recovery.rs` ports fingerprinting and receipt inspection. `core/fixtures/recovery-golden.json` records 5 synthetic submissions x 10 receipt situations, generated by actually executing the exact accepted JavaScript source under Node22.16.0 with WebCrypto. Six new Rust tests include the 50-case oracle and validation boundaries; their pass status is the exact new CI run, not the fixture generation result.

This remains a component, not complete M2: connect it to durable storage, enforce one pending submission per entry/Topic transactionally, preserve the exact payload/request/session and implement the authenticated transport. The lower-level PendingStore permits namespaces for isolated records and must not be mistaken for the final PWA-level topic admission rule. Do not declare HTTP ACK-loss, actual host compatibility or cross-device continuity from pure oracle tests.
